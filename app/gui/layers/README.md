# GUI runtime layers

Эти `gui_app_v*.py` — внутренние слои текущего Streamlit GUI.

- напрямую их не запускайте;
- рабочая точка входа: `app/gui/gui_app.py`, обычно через корневой `run_gui.py`;
- файлы оставлены отдельными, чтобы не рисковать поведением GUI во время структурного рефакторинга;
- неиспользуемые исторические версии переносятся в `archive/legacy/gui/`.

То есть `layers/` — рабочая внутренняя реализация, а не набор пользовательских точек входа.
