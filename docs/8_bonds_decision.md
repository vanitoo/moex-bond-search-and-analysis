# 8_bonds_decision.py — финальные правила решений

Скрипт завершает пункт 3 дорожной карты и объединяет результаты аналитических слоёв в одно решение:

- `Купить`;
- `Рассматривать`;
- `Не покупать`;
- `Недостаточно данных`.

## Вход

Последний файл:

```text
bond_credit_analysis_YYYY-MM-DD.xlsx
```

созданный `7_bonds_credit_analysis.py`.

## Запуск

```bash
python 8_bonds_decision.py
```

Или с явным указанием файла:

```bash
python 8_bonds_decision.py --input bond_credit_analysis_2026-07-27.xlsx
```

## Выход

```text
bond_decisions_YYYY-MM-DD.xlsx
bond_decisions_YYYY-MM-DD.html
bond_candidates_YYYY-MM-DD.json
```

Excel содержит:

- все финальные решения;
- отдельный лист `Кандидаты в портфель`;
- описание правил.

JSON содержит только бумаги с решением `Купить` и служит входом для будущего скрипта виртуального портфеля.

## Порядок принятия решения

1. Проверяются жёсткие стопы.
2. Проверяется полнота рейтинговых и финансовых данных.
3. Проверяются минимальные пороги каждого слоя.
4. Только после этого бумага допускается в пул кандидатов.

Высокая доходность не может компенсировать дефолт, банкротство, критическую долговую нагрузку или слабое покрытие процентов.

## Решение «Купить»

Это не команда немедленно купить бумагу и не готовая структура портфеля.

Это означает, что выпуск:

- прошёл автоматические проверки;
- не имеет обнаруженных стоп-факторов;
- имеет второй аналитический балл не ниже 70;
- имеет кредитный балл не ниже 82;
- имеет рейтинг не ниже `BBB-`;
- не имеет негативного или развивающегося прогноза;
- может участвовать в построении виртуального портфеля.

Следующий портфельный скрипт выберет из этого пула конкретные бумаги и рассчитает доли с учётом стратегии, диверсификации и доступной суммы.

## Решение «Недостаточно данных»

Выставляется, когда отсутствует подтверждённый рейтинг, финансовая отчётность либо уверенность анализа остаётся низкой. Такая бумага не попадает в виртуальный портфель до заполнения данных.

## Жёсткие стопы

В частности:

- дефолт или просрочка;
- банкротство;
- рейтинг `CCC`, `CC`, `C` или `D`;
- критическая долговая нагрузка;
- EBITDA не покрывает процентные расходы;
- критически низкая текущая ликвидность;
- значительный отрицательный денежный поток.
