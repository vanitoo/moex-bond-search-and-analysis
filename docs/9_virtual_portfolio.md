# 9_virtual_portfolio.py — виртуальный портфель

Скрипт формирует и ведёт виртуальные портфели облигаций на основании финального списка кандидатов, созданного `8_bonds_decision.py`.

## Стратегии

### cautious — осторожная

- рейтинг не ниже `A-`;
- итоговый балл не ниже 85;
- до 12 выпусков;
- не более 10% на одну позицию;
- резерв кэша 10%;
- приоритет кредитного качества над доходностью.

### balanced — сбалансированная

- рейтинг не ниже `BBB-`;
- итоговый балл не ниже 82;
- до 10 выпусков;
- не более 12% на одну позицию;
- резерв кэша 5%;
- баланс качества и доходности.

### aggressive — агрессивная

- рейтинг не ниже `BBB-`;
- итоговый балл не ниже 80;
- до 8 выпусков;
- не более 15% на одну позицию;
- резерв кэша 3%;
- больший вес доходности при ранжировании.

## Создание портфеля

```bash
python 9_virtual_portfolio.py create \
  --name balanced_300k \
  --strategy balanced \
  --amount 300000
```

Скрипт автоматически использует последний файл:

```text
bond_candidates_YYYY-MM-DD.json
```

Другой файл можно указать явно:

```bash
python 9_virtual_portfolio.py create \
  --name test \
  --strategy cautious \
  --amount 500000 \
  --candidates bond_candidates_2026-07-27.json
```

## Пополнение и докупка

```bash
python 9_virtual_portfolio.py add --name balanced_300k --amount 50000
```

При докупке используется свежий список кандидатов. Операции добавляются в историю портфеля.

## Анализ портфеля

```bash
python 9_virtual_portfolio.py analyze --name balanced_300k
```

Команда:

- обновляет текущие цены и НКД через MOEX ISS;
- рассчитывает рыночную стоимость;
- рассчитывает нереализованный финансовый результат;
- сопоставляет позиции со свежим `bond_decisions_YYYY-MM-DD.xlsx`;
- показывает текущее решение по каждой бумаге;
- создаёт HTML-отчёт в `reports/`.

## Просмотр состояния

```bash
python 9_virtual_portfolio.py show --name balanced_300k
```

## История операций

```bash
python 9_virtual_portfolio.py history --name balanced_300k
```

История хранит дату, тип операции, код бумаги, количество, цену и сумму.

## Предварительная ребалансировка

```bash
python 9_virtual_portfolio.py rebalance --name balanced_300k
```

Команда только показывает ориентировочный план выравнивания долей. Она не совершает и не записывает операции.

## Где хранятся данные

```text
data/virtual_portfolios/<имя>.json
```

В файле хранятся:

- стратегия;
- внесённая сумма;
- остаток кэша;
- текущие позиции;
- средняя виртуальная цена покупки;
- история операций;
- последнее решение по каждой бумаге.

## Ограничения текущей версии

- это виртуальный учёт без подключения к брокеру;
- комиссии и налоги пока не учитываются;
- купонные выплаты пока не зачисляются автоматически;
- погашения и оферты пока не проводят автоматические операции;
- сравнение трёх портфелей и сравнение с ОФЗ будет отдельным следующим этапом;
- решения `Держать / Не докупать / Сократить / Продать` будут добавлены в модуле анализа уже сформированного портфеля.
