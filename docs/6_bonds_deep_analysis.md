# Скрипт №6 — второй слой анализа облигаций

`6_bonds_deep_analysis.py` запускается после `5_bonds_analysis.py` и анализирует только уже отобранный список выпусков.

## Что проверяется

- дата погашения;
- ближайшая оферта;
- известность будущих купонов;
- амортизация номинала;
- номинал и объём выпуска;
- ограничение для квалифицированных инвесторов;
- локально сохранённые новости;
- наличие в новостях признаков дефолта, просрочки, банкротства, снижения рейтинга и других негативных событий;
- полнота полученных данных.

Расширенные сведения о выпуске загружаются через MOEX ISS. Между запросами выдерживается задержка, поэтому длительность работы зависит от количества выпусков в исходном файле.

## Входной файл

По умолчанию скрипт автоматически выбирает последний файл:

```text
bond_analysis_YYYY-MM-DD.xlsx
```

Можно указать файл вручную:

```bash
python 6_bonds_deep_analysis.py --input bond_analysis_2026-07-27.xlsx
```

## Выходные файлы

```text
bond_deep_analysis_YYYY-MM-DD.xlsx
bond_deep_analysis_YYYY-MM-DD.html
```

HTML-отчёт содержит фильтры по решениям, баллы отдельных блоков, плюсы, риски и список недостающих данных.

## Итоговые решения

- `Рассматривать к покупке`;
- `Рассматривать`;
- `Только небольшой долей`;
- `Ждать и проверить вручную`;
- `Не покупать`;
- `Недостаточно данных`.

Дефолт, просрочка или банкротство являются жёсткими стоп-сигналами и автоматически приводят к решению `Не покупать`.

## Как считаются баллы

- 40% — первичный рыночный балл из скрипта №5;
- до 30 баллов — структура выпуска;
- до 10 баллов — локальные новости;
- до 20 баллов — полнота данных;
- затем применяются штрафы за риски.

## Ограничения текущей версии

Скрипт пока не выполняет полноценный анализ бухгалтерской отчётности эмитента и не получает подтверждённый кредитный рейтинг из официальных источников рейтинговых агентств. Поэтому результат является автоматическим риск-фильтром перед ручной проверкой, а не окончательной инвестиционной рекомендацией.
