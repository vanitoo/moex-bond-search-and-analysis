# Скрипт №7 — кредитный и финансовый анализ эмитента

`7_bonds_credit_analysis.py` — третий аналитический слой после рыночного отбора и проверки структуры выпуска.

## Порядок запуска

```bash
python 5_bonds_analysis.py
python 6_bonds_deep_analysis.py
python 7_bonds_credit_analysis.py
```

Входной файл определяется автоматически:

```text
bond_deep_analysis_YYYY-MM-DD.xlsx
```

Можно указать его явно:

```bash
python 7_bonds_credit_analysis.py --input bond_deep_analysis_2026-07-27.xlsx
```

## Источники данных

Скрипт использует два локальных справочника:

```text
data/issuer_ratings.xlsx
data/issuer_financials.xlsx
```

При первом запуске отсутствующие файлы создаются как пустые шаблоны. После заполнения их нужно сохранить и повторно запустить скрипт.

Допускается CSV с теми же именами:

```text
data/issuer_ratings.csv
data/issuer_financials.csv
```

CSV имеет приоритет над XLSX.

Запись связывается с выпуском в следующем порядке:

1. код ценной бумаги;
2. ИНН;
3. название эмитента.

Для надёжной связи рекомендуется всегда заполнять код бумаги или ИНН.

## Рейтинги

Поддерживаются национальные рейтинговые шкалы от `AAA` до `D`, в том числе формы `AAA(RU)` и `ruAAA`.

Учитываются:

- текущий рейтинг;
- агентство;
- прогноз;
- дата рейтинга;
- предыдущий рейтинг;
- повышение или снижение;
- устаревание рейтинга.

Рейтинги `CCC`, `CC`, `C` и `D` создают жёсткий стоп.

## Финансовые показатели

Исходные суммы должны быть указаны в одной валюте и одной размерности в пределах строки. Например, все показатели можно вводить в миллионах рублей.

Скрипт рассчитывает:

- долг / EBITDA;
- чистый долг / EBITDA;
- EBITDA / процентные расходы;
- текущую ликвидность;
- долг / собственный капитал;
- маржу EBITDA;
- чистую маржу;
- операционный денежный поток / долг.

Система не смешивает данные разных периодов и берёт одну наиболее подходящую строку. Для текущей версии рекомендуется хранить в файле только последний подтверждённый период по каждому эмитенту.

## Итоговая формула

```text
30% результата второго слоя
+ до 30 баллов за рейтинг
+ до 30 баллов за финансовое состояние
+ до 10 баллов за полноту данных
- штрафы за риски
```

Финальные решения:

```text
Допустить к покупке
Рассматривать
Только небольшой долей
Ждать и перепроверить
Не покупать
Недостаточно данных
```

## Результаты

```text
bond_credit_analysis_YYYY-MM-DD.xlsx
bond_credit_analysis_YYYY-MM-DD.html
```

HTML содержит фильтры и карточки с рейтингом, ключевыми коэффициентами, положительными факторами, рисками и недостающими данными.

## Ограничения

Скрипт намеренно не парсит сайты рейтинговых агентств и бухгалтерскую отчётность вслепую. Автоматическое сопоставление непроверенных публикаций способно дать опасную ошибку. В шаблоны следует переносить данные из официальных публикаций эмитента, рейтингового агентства или проверенного провайдера.

EBITDA у разных источников может рассчитываться по разной методике. В одной базе нужно использовать сопоставимую методику и указывать источник.
